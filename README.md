# zevamandi.foo.ng

A short address for **Zeva Mandi & Grills**, Bolar, Mangaluru. This repository is
nothing but a redirect: GitHub Pages serves it on `zevamandi.foo.ng` (the `CNAME`
file) and the page forwards visitors — path and query intact — to the live site
on `freebuff.page`, which is where the menu, the ordering app and the payment
flow actually run.

The name itself is registered through the free `foo.ng` registry
([Pokymon/foo.ng](https://github.com/Pokymon/foo.ng)) with one CNAME record
pointing here.
